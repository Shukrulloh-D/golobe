# Задание

Сверстать многостраничный сайт бронирования путешествий (авиабилеты + отели) — лендинг, поиск и бронирование перелётов, поиск и бронирование отелей, личный кабинет, авторизация/регистрация. Сайт многостраничный (десктоп + адаптив под планшет и мобильные устройства).

# Общие элементы

шапка — логотип слева, по центру/справа — горизонтальное меню («Авиабилеты», «Отели», «О компании» и т.п. — точные подписи уточнить по макету), иконки поиска/избранного, кнопка входа/профиль;
футер — ссылки по разделам, контакты, копирайт внизу;
сквозная светлая цветовая схема с крупными фотографиями направлений; акцентные цвета — тёмно-синий и оранжевый (диагональные градиентные плашки в блоке аккаунта), зелёные кнопки действий («В корзину»/«Забронировать» и т.п.);
карточки предложений с единообразной структурой: фото — название/направление — краткие параметры — цена — кнопка действия.

# Страницы
# Главная (Landing) —
hero-баннер с промо-слоганом («Live & Travel» — уточнить по макету) и переходом к поиску;
сетка карточек популярных направлений/предложений с фото;
дополнительный блок карточек (акции/подборки);
футер с контактами.
# Flight Flow (перелёты) — цепочка экранов:
форма поиска рейсов (откуда/куда, даты, пассажиры) на фоне фото;
страница результатов поиска — список рейсов с фильтрами сбоку, ценами и временем в пути;
карточка/страница деталей выбранного рейса (маршрут, фото, цена, кнопка выбора);
форма ввода данных пассажира;
экран оплаты (тёмный фон, форма карты — модальное окно);
экран подтверждения бронирования.
# Hotel Flow (отели) — цепочка экранов:
форма поиска отеля (город, даты заезда/выезда, гости) на фоне фото;
список отелей — карточки с фото, рейтингом, ценой, фильтры сбоку;
страница отеля — фотогалерея, описание, характеристики, цена, кнопка бронирования;
экран с картой и расположением отеля;
форма данных гостя;
экран оплаты (тёмный фон, форма карты — модальное окно);
экран подтверждения бронирования.
# Account Flow (личный кабинет) —
профиль пользователя — шапка-баннер (диагональный градиент тёмно-синий/оранжевый), данные пользователя;
страница истории бронирований — список карточек с поездками;
страница способов оплаты — список привязанных карт;
модальное окно (тёмный оверлей) с формой добавления/редактирования данных.
# Login / Sign up —
экран входа — форма (email/телефон, пароль);
экран регистрации — форма (имя, email, пароль, подтверждение);
сетка карточек направлений/отелей сбоку или на фоне как визуальное сопровождение экранов авторизации (уточнить по макету, какие именно карточки предусмотрены).

# Адаптивность
десктоп — многоколоночные сетки карточек, боковая колонка с фильтрами на страницах результатов поиска;
планшет — сетки сужаются до 2–3 колонок, меню сворачивается в бургер, боковые блоки (фильтры, карта) уходят под основной контент;
мобильная версия — всё в один стек, карточки в вертикальном списке, шаги бронирования (поиск → результаты → детали → данные → оплата → подтверждение) — по одному экрану за раз, формы и карта — на всю ширину.
